# Key

One API key of your workspace. A key belongs to exactly one environment. key, the secret credential, is present only in the answer that created the key: NoResponse keeps a peppered digest of it, so store it now. Every other field is safe to show.

## Example Usage

```typescript
import { Key } from "@noresponse/node/models";

let value: Key = {
  id: "01JA2ZE4K5M6N7P8Q9R0S1T2V3",
  workspaceId: "tnt_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  environment: "test",
  prefix: "nrk_live_01JA2ZE4K5M6N7P8Q9R0S1T2V3",
  scopes: [
    "delete",
  ],
  status: "revoked",
  createdAt: "2026-10-23T09:14:12.000Z",
  createdBy: "nrk_live_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  expiresAt: "2026-10-24T09:14:12.000Z",
  revokedAt: "2026-10-25T09:14:12.000Z",
  revokedBy: "nrk_live_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  key:
    "nrk_live_01JA2ZE4K5M6N7P8Q9R0S1T2V3_N0tARealSecretJustTheShapeOfOneAAAAAAAAAAAA",
};
```
