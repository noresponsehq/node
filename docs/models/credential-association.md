# CredentialAssociation

An association between an account and an issued key. The response excludes the key and its hash. Retirement removes this association from risk calculations; revoke the actual key through your own service.

## Example Usage

```typescript
import { CredentialAssociation } from "@noresponse/node/models";

let value: CredentialAssociation = {
  id: "cred_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  accountId: "acct_7f3a9c",
  createdAt: "2026-01-01T00:00:00Z",
  retiredAt: "2026-01-01T00:00:00Z",
  actor: {
    type: "api_key",
    keyId: "01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  },
  retiredBy: {
    type: "api_key",
    keyId: "01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  },
};
```
