# AccountBinding

Binding appends an assessment revision and preserves earlier versions. Continuations use the same assessment. Erasing either the provisional or canonical name erases the canonical account, including the bound assessment.

## Example Usage

```typescript
import { AccountBinding } from "@noresponse/node/models";

let value: AccountBinding = {
  assessmentId: "asm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  provisionalAccountId: "pre:asm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  accountId: "acct_7f3a9c",
  assessmentVersion: 652776,
  createdAt: "2026-01-01T00:00:00Z",
  actor: {
    type: "api_key",
    keyId: "01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  },
};
```
