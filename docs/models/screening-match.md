# ScreeningMatch

How a profile was matched to the attendee: the state its evidence earns, and the evidence.

## Example Usage

```typescript
import { ScreeningMatch } from "@noresponse/node/models";

let value: ScreeningMatch = {
  state: "probable",
  evidence: [],
};
```
