# AccountDecisionSnapshot

Retrieve the account decision at one recorded risk version. The answer uses the original assessment and account-specific risk inputs. Earlier versions that were not captured return 404. The assessment version, policy version and account calculation version identify the decision.

## Example Usage

```typescript
import { AccountDecisionSnapshot } from "@noresponse/node/models";

let value: AccountDecisionSnapshot = {
  account: {
    schemaVersion: "1",
    id: "acct_7f3a9c",
    risk: {
      score: 557856,
      decision: "step_up",
      reasons: [
        {
          code: "voip_number",
          direction: "neutral",
          impact: "medium",
          listEntryId: "lst_01JA2ZE4K5M6N7P8Q9R0S1T2V3",
        },
      ],
    },
    decisionsByFlow: {
      accountCreation: "block",
      login: "allow",
      purchase: "held",
    },
    assessmentId: "asm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
    updatedAt: "2026-10-14T09:00:00.412Z",
    riskVersion: 698486,
  },
  assessmentVersion: 799136,
  policyVersion: "risk-2026-10.17+t1",
  overlayVersion: 1,
  changedAt: "2026-01-01T00:00:00Z",
  feedbackOutcomeId: "out_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
};
```
