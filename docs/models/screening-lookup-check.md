# ScreeningLookupCheck

What came of one lane of the lookups for one identifier.

## Example Usage

```typescript
import { ScreeningLookupCheck } from "@noresponse/node/models";

let value: ScreeningLookupCheck = {
  identifier: "phone",
  lane: "accounts",
  status: "not_covered",
  sources: 262143,
  answered: 191528,
  found: 400716,
};
```
