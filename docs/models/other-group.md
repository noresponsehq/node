# OtherGroup

A person of another group in the same environment who shares an email or phone with this one, as that group recorded them.

## Example Usage

```typescript
import { OtherGroup } from "@noresponse/node/models";

let value: OtherGroup = {
  groupId: "grp_01J9Y3C2M4N6P8Q0RSTVWXYZAB",
  groupName: "Spring gala",
  groupStartsAt: "2025-09-01T09:00:00Z",
  personId: "per_01J9Y3C2M4N6P8Q0RSTVWXYZAB",
  matchedOn: [],
  matchState: "unscreened",
  highestBand: "critical",
  decision: "watch",
  decidedBy: "user_2abc",
  decidedAt: "2025-09-01T12:00:00Z",
};
```
