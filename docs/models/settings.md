# Settings

One environment's settings: how long its assessments are kept, and for each flow the risk thresholds that decide it and the depth a request that names none is served at, and the sources it refuses. Live and test each have their own. A flow without thresholds of its own uses account_creation's (inherits_account_creation). Every change is recorded in the audit log as settings.updated, with who made it.

## Example Usage

```typescript
import { Settings } from "@noresponse/node/models";

let value: Settings = {
  workspaceId: "tnt_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  environment: "test",
  retentionDays: 806360,
  policyVersion: 527807,
  updatedBy: "nrk_live_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  updatedAt: "2026-10-23T09:14:12.000Z",
  flows: {
    accountCreation: {
      stepUp: 630555,
      review: 62705,
      defaultDepth: "quick",
      inheritsAccountCreation: false,
      admission: "immediate",
      holdSeconds: 580362,
      onExpiry: "review",
    },
    login: {
      stepUp: 930785,
      review: 521557,
      defaultDepth: "quick",
      inheritsAccountCreation: false,
      admission: "immediate",
      holdSeconds: 131973,
      onExpiry: "block",
    },
    purchase: {
      stepUp: 207860,
      review: 558525,
      defaultDepth: "quick",
      inheritsAccountCreation: false,
      admission: "immediate",
      holdSeconds: 466586,
      onExpiry: "block",
    },
  },
  refusedSources: [],
};
```
