# ScreeningFinding

Something the analyser flagged. band is capped by the strongest match among the profiles of its evidence: possible at most moderate, probable at most high. capped_from is the band the analyser gave when the cap lowered it.

## Example Usage

```typescript
import { ScreeningFinding } from "@noresponse/node/models";

let value: ScreeningFinding = {
  id: "fnd_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  category: "security_research",
  band: "critical",
  confidence: 2145.7,
  rationale: "The post reports when the principal leaves the hotel.",
  quote:
    "Spotted Jordan Lee leaving the hotel, they always take the side exit at seven.",
  evidence: [
    "itm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  ],
  mediaObservations: [
    {
      mediaId: "itm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
      description: "A handwritten sign held up outside the venue.",
      readText: "SEE YOU ON THE 1ST",
    },
  ],
  analyser: "synthetic",
  model: "synthetic-1",
  spendMinor: 154515,
  createdAt: "2026-01-01T00:00:00Z",
};
```
