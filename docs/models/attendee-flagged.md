# AttendeeFlagged

A screening recorded a finding on an attendee. It says which attendee and how severe, not what they posted, who they are or why: GET the attendee report for the findings. Sent once per screening that flags the attendee, so a re-screen of someone on watch announces them again.

## Example Usage

```typescript
import { AttendeeFlagged } from "@noresponse/node/models";

let value: AttendeeFlagged = {
  eventId: "evn_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  attendeeId: "att_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  screeningId: "scn_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  highestBand: "moderate",
  matchState: "confirmed",
  flaggedAt: "2026-11-20T07:41:09.000Z",
};
```
