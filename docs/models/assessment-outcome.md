# AssessmentOutcome

The 202 answer of POST /v1/assessments/{assessment_id}/outcomes. A replay with the same Idempotency-Key and body answers the same record.

## Example Usage

```typescript
import { AssessmentOutcome } from "@noresponse/node/models";

let value: AssessmentOutcome = {
  id: "<id>",
  assessmentId: "<id>",
  outcome: "confirmed_abuse",
  receivedAt: "<value>",
};
```
