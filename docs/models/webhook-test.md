# WebhookTest

The 202 answer of POST /v1/webhooks/{endpoint_id}/test: the event that was sent or queued.

## Example Usage

```typescript
import { WebhookTest } from "@noresponse/node/models";

let value: WebhookTest = {
  deliveryId: "evt_01JA2ZD3K4M5N6P7Q8R9S0T1V2",
  endpointId: "whe_01JA2ZD0E1F2G3H4J5K6M7N8P9",
  event: "endpoint.verification",
  state: "unverified",
};
```
