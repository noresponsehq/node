# Coverage

Counts only; a zero denominator means no eligible retained records and does not imply a zero rate.

## Example Usage

```typescript
import { Coverage } from "@noresponse/node/models";

let value: Coverage = {
  numerator: 581529,
  denominator: 255766,
};
```
