# ScreeningMediaObservation

What an analyser saw in one image that a finding rests on.

## Example Usage

```typescript
import { ScreeningMediaObservation } from "@noresponse/node/models";

let value: ScreeningMediaObservation = {
  mediaId: "itm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  description: "A handwritten sign held up outside the venue.",
  readText: "SEE YOU ON THE 1ST",
};
```
