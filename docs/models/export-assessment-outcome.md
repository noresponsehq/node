# ExportAssessmentOutcome

Structured fields of a retained per-assessment outcome. Legacy notes remain private as promised by the existing outcome contract.

## Example Usage

```typescript
import { ExportAssessmentOutcome } from "@noresponse/node/models";

let value: ExportAssessmentOutcome = {
  id: "out_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  assessmentId: "asm_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  outcome: "unknown",
  observedAt: "2026-01-01T00:00:00Z",
  receivedAt: "2026-01-01T00:00:00Z",
  externalRef: "case_123",
};
```
