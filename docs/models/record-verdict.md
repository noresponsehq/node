# RecordVerdict

A recorded verdict on one record. A later verdict on the same record replaces it.

## Example Usage

```typescript
import { RecordVerdict } from "@noresponse/node/models";

let value: RecordVerdict = {
  recordId: "rec_3f9a1c22d4e5b6a73f9a1c22d4e5b6a7",
  verdict: "rejected",
  decidedBy: "user_2abc",
  decidedAt: "2026-01-01T00:00:00Z",
};
```
