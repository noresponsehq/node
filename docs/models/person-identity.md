# PersonIdentity

What you know about a person. Stored encrypted under the workspace's key.

## Example Usage

```typescript
import { PersonIdentity } from "@noresponse/node/models";

let value: PersonIdentity = {
  externalId: "ticket-1042",
  name: "Jordan Example",
  email: "jordan@company-example.com",
  phone: "+14155550100",
  company: "Example Ltd",
  city: "Melbourne",
  handles: [
    {
      platform: "threads",
      handle: "jordan_example",
    },
  ],
};
```
