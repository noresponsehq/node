# AggregateScoreCount

First answers of one flow whose risk.score is in [score_min, score_max]: 0-4, 5-9 up to 95-100. A pending answer has no score.

## Example Usage

```typescript
import { AggregateScoreCount } from "@noresponse/node/models";

let value: AggregateScoreCount = {
  flow: "account_creation",
  scoreMin: 716697,
  scoreMax: 566540,
  count: 179796,
};
```
