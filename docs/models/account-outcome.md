# AccountOutcome

Immutable acceptance receipt. risk_version is the account version after this report committed, not the version when a retry reads it. effective_outcome_id names the effective head at that write. The effective expiration may shorten under retention changes. A legitimate report or correction removes only the account-feedback contribution, not unrelated risk.

## Example Usage

```typescript
import { AccountOutcome } from "@noresponse/node/models";

let value: AccountOutcome = {
  id: "out_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  accountId: "acct_7f3a9c",
  outcome: "false_positive",
  supersedes: "out_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  observedAt: "2026-01-01T00:00:00Z",
  receivedAt: "2026-01-01T00:00:00Z",
  expiresAt: "2026-01-02T00:00:00Z",
  externalRef: "case_123",
  actor: {
    type: "api_key",
    keyId: "01JA2Z8K6Q4V7W9XBCDEFGHJKM",
    externalUserId: "usr_customer_admin",
    consoleCredentialId: "01JA2Z8K6Q4V7W9XBCDEFGHJKM",
    principalId: "mem_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  },
  riskVersionBefore: 992962,
  riskVersion: 354508,
  effectiveOutcomeId: "out_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
};
```
