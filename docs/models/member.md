# Member

One member of a workspace: an external user id holding one role. A removed member loses every permission at once.

## Example Usage

```typescript
import { Member } from "@noresponse/node/models";

let value: Member = {
  id: "mem_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  workspaceId: "tnt_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  externalUserId: "user_teammate",
  role: "auditor",
  status: "active",
  createdAt: "2026-01-01T00:00:00Z",
  updatedAt: "2026-01-01T00:00:00Z",
  principalId: "mem_01JA2Z8K6Q4V7W9XBCDEFGHJKM",
  displayName: "Alex Example",
  unverifiedEmail: "alex@example.com",
};
```
